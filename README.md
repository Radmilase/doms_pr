# Оптимизация параметров роботизированного захвата в MuJoCo с применением RL.

## Цели этого проекта:
\item Смоделировать захват, сцену и тестируемые объекты в MuJoCo;
    \item Разработать систему управления, реализовать регулятор;
    \item Провести оптимизацию;  
    \item Провести тестирование и анализ результатов.
